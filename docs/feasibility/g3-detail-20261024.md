## Behavior

The [user service](../../pact/users.py) derives the participant from a verified session.
It reads the signed agreement, checker reports, payment evidence references, and participant budget within one database transaction.
It reports finalization, authorization, rework, unknown payment, closure, and confirmed payment states.
Unknown capture retains reservations and permits query-only recovery.
Unknown order remains on hold.
Stop and expiry flags do not replace unknown payment state.
Queries never dispatch payment, image processing, or file writes.

The budget uses the participant's original committed period.
It separates reserved amounts, consumed amounts, transaction reservations, and remaining amounts.
The response excludes payment tokens, encrypted payloads, session secrets, and private PayPal account identifiers.
Buyer output permission requires confirmed payment.
Provider output permission requires a committed capture intent.
Permission does not establish file availability.
The response explicitly reports unverified retention policy.
