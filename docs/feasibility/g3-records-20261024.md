## Behavior

The [record service](../../pact/records.py) signs minimal ordering records with an external Ed25519 key.
Each record binds its sequence, event kind, target hash, evidence hash, timestamp, and previous receipt hash.
A signed summary binds the current record count and head hash.
The database pins the service origin and public key.
A changed identity prevents publication after restart.
Publication checks existing receipt signatures and their exact correspondence with ordered events.
Concurrent publication creates one receipt per event.
Failed publication rolls back every new receipt.

Both transaction participants can export their signed agreement, Mandates, proposals, checker reports, payment assertion, and relevant receipts.
The service checks the authenticated participant and evidence hashes before signing the export.
It includes later signed revocations and applicable stop records.
The export excludes saved payment tokens, encrypted request bodies, source images, and private PayPal account identifiers.
Public records contain hashes instead of source documents or raw target identifiers.
Hashes of predictable identifiers do not guarantee anonymity.

## Trust and limits

Server signatures authenticate server assertions.
They are not PayPal signatures or independent proof of financial settlement.
Authenticated payment readback remains the settlement authority.
The export contains readback hashes rather than complete readback documents.
Independent parties must retain published receipts and summaries to compare server assertions.
The implementation cannot prevent consistent server collusion or prove events that were changed before first publication.

Publication currently scans the complete event history.
It supports the bounded local demonstration rather than an unlimited public service.
Receipt creation occurs when the record service is called.
Automatic publication, delivery notifications, HTTP access, and independent receipt storage remain unimplemented.
The external signing key has no rotation or recovery workflow.
