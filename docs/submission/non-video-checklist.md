## Access choice

The submission uses complete public repository instructions instead of a hosted service.
Judges do not need entrant credentials for the synthetic suite or empty local interface.
Actual PayPal Sandbox commerce needs separate account consent and entrant-owned credentials.
Do not publish those credentials in the repository or submission text.
