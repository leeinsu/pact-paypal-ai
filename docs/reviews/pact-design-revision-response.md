입력: [설계 완성도 재평가](pact-design-completeness-review.md). 대상: [설계 수정안](../pact-revision-proposal.md).
수정 본문 SHA-256: `19c133451acb96348efcc9a79b122c637c37c3a8e1a2b9aeb4c07c0ff97a22db`.

이번 작업은 제안의 결정과 검증 계획을 보완했다. 설계 채택, 구현, 실험 실행이나 점수 재산정을 뜻하지 않는다.
기존 PACT·GLOSSARY·README·ADR과 과거 평가 기록은 변경하지 않았다. R1~R13과 GD·G1~G5를 유지했다.

## 지적별 결정과 반례

행 번호는 위 해시의 수정안 기준이다. “반영”은 문서에 결정을 적었다는 뜻이며 기능 검증 완료가 아니다.

| 지적 | 결정과 변경 위치 | 설계에 추가한 반례·판단 | 남은 미검증 사항 |
| --- | --- | --- | --- |
| D1 지급 제출 후 기한 | 반영. §6 127행, §8 184행, §10 255행. 합의 기한은 지급 제출 커밋 전까지 적용한다. 이후에는 같은 지급 의도를 유지한다. 외부 승인 만료를 분리한다. | 제출 커밋→HTTP 전 종료→기한 경과→재시작. 유효 승인·안전한 재시도 조건이면 기존 요청 처리. 미지급과 지급 불가능을 확인해야 예약 해제. | 실제 API의 승인 만료 상태와 조회·재시도 지원은 G1에서 확인해야 함 |
| D2 앱 인증·객체 권한 | 반영. §4 75행. 기기 서명으로 로그인과 Principal을 연결한다. 계정 변경·파일·정지·운영자 권한표와 서버 암호화 열쇠의 보관 주체를 추가했다. | 다른 Principal의 객체 ID, 난수 재사용, 서명 목적 변경, PayPal 복귀 연결 불일치, 운영자의 권한 초과 요청을 거부하도록 설계. | 인증·권한 코드는 미구현. 서버 호스트 관리자에 대한 파일 비밀성은 보장하지 않음 |
| D3 장기 지급 불명 | 반영. §6 137행, §8 187행, §10 257행. 담당자·허용 증거·처리 권한·감사·문의·이의 제기를 정했다. | 완료 확인, 미지급 및 지급 불가능 확인, 확인 불가를 분리. 세 번째는 영구 예약 유지 가능. 근거 없는 상태 변경 금지. | 수동 증거의 진위·해석은 담당자 확인에 의존. G1에서 증거 항목을 정하기 전 수동 종결 불가 |
| D4 실제 적용률·경제성 | 반영. §2 26행, §10 258행. 연속 고객 표본, 적용률·시간·비용·설정 부담의 기각 기준을 추가했다. | G2를 통과해도 실제 적용률이나 경제성 기준에 실패하면 고객·작업 가설을 재검토. 자료 부족은 미확정. | 고객 자료·비교 측정은 없음. 수치는 초기 가설이며 시장 전체에 일반화할 수 없음 |
| D5 단순 자동 지급 비교 | 반영. §9 211행, §10 258행. 같은 검사·지급 기반의 결정 코드 비교군을 추가했다. 직접 비교의 시간·비용 기각 기준도 명시했다. | 일정 조건 10건과 변경 조건 10건 비교. 교집합 선택 코드가 개입·제한 위반·합의 결과·시간·비용에서 같은 성과면 협상 우월성 주장 제외. 불가능한 합의는 양쪽 모두 거부해야 함. | 협상의 추가 가치와 AI의 실질적 역할은 비교 후 판단해야 함 |
| 발표 보완 | 반영. §9 228행. 핵심 55초를 같은 거래의 합의 15초·검사 20초·지급과 파일 대조 20초로 구분했다. | 거래 번호를 고정하고 합의·출력 해시를 지급 기록까지 연결. 다른 거래 기록의 혼합을 허용하지 않음. | 화면과 영상은 미구현. 실제 소요 시간은 미검증 |

## 독립 1차 검토 후 보완

독립 `metis` 검토는 D5의 시간·비용 비교 기준이 §2의 사람 검사·지급 비교군을 가리킬 수 있다고 지적했다.
§9 213행에 결정 코드 비교군 대비 시간 중앙값 20%·건별 비용 중앙값 10% 초과 증가 시 기각한다는 기준을 직접 적었다.
§9 214행은 동일 성과에 개입·제한 위반·합의 결과·시간·비용이 포함됨을 명시했다. 임계값과 나머지 범위는 바꾸지 않았다.
독립 검토자 `pact_design_revision_verify` / `metis`가 수정 본문을 재확인했다. 최종 판정은 **ACCEPT**다.

## 독립 검토 결과

주 에이전트가 독립 검토자의 결과를 기록했다. 검토 대상은 이 문서 상단의 최종 본문 해시다.
1차 검토는 D1~D4와 발표 보완을 해소로 판단했다. D5의 비교 기준을 보완한 뒤 최종 검토도 해소로 판단했다.
검토자는 새 필수 설계 충돌을 발견하지 못했다. 이 판정은 지적 반영에 대한 설계 검토이며 구현 승인이나 실험 통과가 아니다.

검토자는 [공식 페이지](https://paypalaihackathon.devpost.com/)의 `Judging Criteria`와 `Requirements`, [공식 규정 §4](https://paypalaihackathon.devpost.com/rules)를 열어 확인했다.
다섯 공식 심사 항목에는 [프로젝트 지침](../../AGENTS.md)의 설계 관점을 적용했다. 수치 점수는 재산정하지 않았다.

| 적용 기준 | 검토한 설계 근거 |
| --- | --- |
| 기술 구현: 권한 경계·실패 처리 | D1 기한 경계, D2 인증·객체 권한, D3 증거에 따른 지급 상태 처리 |
| 디자인: 실패 복구·다음 행동 | D1 사용자 표시, D3 담당자·문의·이의 제기·예약 유지 |
| 잠재 영향: 고객 문제·검증 방법 | D4 실제 의뢰 표본과 적용률·경제성의 사전 기각 기준 |
| 혁신성: 추가 구조의 필요성 | D5 같은 조건의 결정 코드 비교군과 실패 시 주장 축소 |
| 발표: 거래 흐름의 입증 방법 | 동일 거래의 합의·검사·지급·파일을 연결하는 55초 구성 |
| 필수 요구: PayPal·AI의 실질적 통합 | G1 sandbox 연동 계획과 D5 실패 시 AI 역할 재검토 |

권한·복구·가치 기각 조건은 공식 심사 항목을 설계 범위에 맞게 해석한 내부 기준이다.
구현·실험·영상·제출 자료의 준비 여부는 사용자 지시에 따라 판정에서 제외했다.
실제 API 상태와 수동 확인 증거는 G1에서 확인할 사항으로 남겼다. 이번 리뷰는 새 API 사실을 확정하지 않았다.

## 초기 가설값의 취급

§2의 3명·60건·적용률 60%·개입 시간 50% 절약·시간 20% 및 비용 10% 증가 한도·설정 30분·100건 내 회수는 조사 시작점을 정한 값이다.
반복되는 고객 문제, 다수 의뢰에 대한 적용 가능성, 설정을 감수할 절약과 초기 허용 비용을 확인하려는 기준이다. 실제 결과나 외부 권고값이 아니다.
§9의 변경 10건 중 개입 2건 감소는 20% 차이를 탐색하는 초기 기준이다. 비교군에도 같은 조건 정보와 후보를 제공한다.
실험 전에 표본과 기준을 고정한다. 기준을 바꾸면 이유를 기록하고 새 표본으로 평가한다.
로그인 요청의 5분 만료와 지원 접수의 1영업일 목표도 제안한 운영값이다. 사용성 검증이나 해결 시간 보장은 없다.

## 언어 검토

검토 범위는 이번에 추가·수정한 본문과 이 대응 기록이다. 공통 용어집의 Principal·사용자 서명 열쇠·결제 승인·긴급 정지·보관 종료일을 확인했다.
앱 세션, 적용률, 상태 처리기를 본문에서 설명했다. 로그인 절차와 핵심 시연 순서는 목록으로 나눴다.
D1의 기한 적용 경계, D3의 수동 확인 신뢰 범위, D4·D5의 수치와 미검증 조건을 원래 지적과 수동 대조했다. D5 후속 수정에서는 직접 비교 대상과 임계값의 의미 보존을 다시 확인했다.
식별자·해시·API 이름·쿠키 속성은 정확한 표기를 유지했다. 이 표기는 언어 단순화 대상에서 제외한다.
확인된 나머지 문장 규칙 예외는 없다. 기존 문서 전체의 언어 재작성과 공식 ASD-STE100 승인 어휘 검증은 수행하지 않았다.
독립 검토도 공통 용어와 사실·가설·미검증의 구분을 확인했다. 조건과 신뢰 한계를 보존하기 위해 일부 문단은 길이를 유지했다.
주 에이전트는 추가한 독립 검토 기록의 용어와 판정 범위를 수동 대조했다.

## 검증 범위

본문의 각 D 지적과 대응 위치를 대조했다. 상대 파일 링크, R1~R13·GD·G1~G5의 존재, 공백 오류와 본문 해시를 확인했다.
구현 테스트·PayPal sandbox 호출·고객 조사·영상 제작은 수행하지 않았다. 제출 준비도와 설계 점수는 채점하지 않았다.
